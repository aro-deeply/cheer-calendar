# 화이팅 달력

달마다 다른 응원 캐릭터가 나와서 "화이팅!"을 외쳐 주고, 내 꿈과 이달 목표를 불러 주는 모바일 달력입니다. Claude와 함께 만든 실습용 프로젝트입니다.

## 기능

- 12달 응원단: 1월 흰곰 눈곰이부터 12월 아기 양 몽실이까지, 달마다 다른 캐릭터와 배경 효과
- 꿈 불러 주기: "내 꿈"에 적은 내용을 그달 캐릭터가 응원 문장에 넣어 줌
- 이달 목표: 달마다 목표 한 줄을 적으면 캐릭터가 함께 응원
- 캐릭터를 누르면 점프하면서 다른 응원 문장으로 바뀜
- 한국 공휴일·대체공휴일 표시 (2026~2027년)
- 날짜별 메모, 메모 있는 날 점 표시
- 달력 좌우 스와이프로 달 넘기기

## 실행 방법

설치할 것 없이 `index.html`을 브라우저로 열면 됩니다.
꿈, 목표, 메모는 브라우저의 localStorage에 저장됩니다. 그래서 같은 브라우저에서만 이어서 보입니다.

## 구조

- `index.html` 한 파일에 HTML, CSS, JavaScript가 모두 들어 있습니다.
- 캐릭터는 이미지 파일 없이 JavaScript가 SVG로 그립니다 (`charSVG` 함수).
- 응원 문장은 `CREW` 배열에서 고칠 수 있습니다. `{v}`는 부르는 이름, `{d}`는 꿈, `{g}`는 이달 목표로 바뀝니다.
- 공휴일은 `HOLIDAYS` 객체에 날짜별로 들어 있습니다.
